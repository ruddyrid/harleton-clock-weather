# Harleton, TX — Tablet Clock & Weather Homepage

A self-contained tablet homepage dashboard displaying a dual analog + digital clock and live weather for **Harleton, Texas** (`32.68°N, 94.57°W`, `America/Chicago`).

## Features
- **Dual Analog & Digital Clock**: Customizable dial markings, smooth sweep or 1-second tick motion, 12h/24h mode, and stacked or side-by-side layout.
- **Live Harleton Weather**: Powered by Open-Meteo (temperature, feels-like, high/low, humidity, cloud cover, wind speed & direction, pressure, rain chance, UV index, sunrise/sunset, 8-hour and 5-day forecasts) plus active NOAA/NWS alerts.
- **Light & Dark Theme Variances**: 8 curated themes (*Midnight Slate*, *OLED Obsidian*, *Piney Woods Dusk*, *Warm Ember*, *Daylight Paper*, *Pure Crisp*, *Morning Meadow*, *Golden Hour*) plus automatic sunrise/sunset switching.
- **Typography & Alpha Channels**: Customizable clock/UI fonts, font weight, digital scale, glass blur, and individual alpha sliders for card surfaces, analog dial, text, borders, and ambient/wallpaper backdrop.
- **Tablet Ready**: Responsive layout, Fullscreen button, Screen Wake Lock (`Keep Awake`), and persistent `localStorage` preferences.
